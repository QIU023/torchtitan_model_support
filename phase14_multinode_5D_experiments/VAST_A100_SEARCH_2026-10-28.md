# vast.ai 上找两台能组多节点的 8×A100（2026-10-28 快照）

用户："调取vast ai 多节点相关的记忆怎么配置，帮我找两个8*A100的container需要能组多节点"。CPU 会话用本机的 vastai CLI 1.5.0 查询，只搜索，没有租用。

## 多节点的配置方法（之前的记录）

出处：`phase13_k3like_48b_posttrain/VAST_MULTINODE_CRITERIA_2026-08-29.md`、`phase13_k3like_48b_posttrain/multinode/README.md`（07-26 那对 2×8 5060 Ti）。

- 两台机器必须在同一个 `cluster_id` 里，而且只能用 Docker 模板（overlay 私网不支持 VM 模板）。
- 没有 overlay，容器之间就组不了 NCCL：
  - rendezvous 只用一个端口，走主机局域网加转发端口也能连上；
  - NCCL 的数据面在每个容器的 docker bridge（`172.17.0.x`）上开临时端口，跨不过 NAT；容器里也没有 `/dev/net/tun`，自己搭 WireGuard 不行；
  - 07-26 那对 5060 Ti 是同一个 host、同一个 /24 局域网，但没有 `cluster_id`，最后卡在这一步。
- 租用流程：

```sh
vastai search offers 'cluster_id!=None num_gpus=8 gpu_name=A100_SXM4' --raw   # 找同一 cluster 的两台
vastai create overlay <CLUSTER_ID> p14net
vastai create instance <offer_A> --image <img> --env "-n p14net" ...
vastai create instance <offer_B> --image <img> --env "-n p14net" ...
# 已经在跑的实例可以 vastai join overlay p14net <instance_id>
# 容器里：NCCL_SOCKET_IFNAME=eth0（join 的实例要用 ip a 看新网卡），MASTER_ADDR 用 node 0 的 overlay 地址
```

- overlay 是虚拟以太网，NCCL 走 socket，不走 InfiniBand。跨节点带宽取决于机房网络，multinode.md 里每卡 200 到 400 Gb/s 网卡的假设在 vast 上不成立，E2、E3 的跨节点部分要按实测重估。

## 查询结果

```sh
vastai search offers 'cluster_id!=None verified=any' --raw --limit 2000
vastai search offers 'gpu_name in [A100_SXM4,A100_PCIE,A100X] num_gpus=8 verified=any' --raw
vastai search offers 'gpu_name in [A100_SXM4,A100_PCIE,A100X] gpu_ram>=70 verified=any' --raw
```

- **带 `cluster_id` 的报价，全市场只有 13 个，分属 4 个 cluster，没有一台 A100：**

| cluster | 机器（machine_id, 最大切片卡数） | 能不能组 2 × 8 |
|---|---|---|
| 46 | 5060 Ti（13124, 4；31841, 1），4090（10685, 1），3060（14114, 1） | 不能 |
| 61 | 4090（16299, 1） | 不能 |
| 80 | 5090（7506、8357、8461、35150，各 8 卡，$6.93 到 $8.00/h；1569, 1） | **能**，4 台 8×5090 任选两台，约 $14.4/h 起 |
| 90 | H200（34325, 8 卡） | 不能，只有一台 |

- **8×A100 的整机报价只有 5 个，全是 40GB：** 4 台 PCIe、1 台 SXM4（加州 $3.84/h），各属不同的 host，都没有 `cluster_id`。
- **A100 80GB：** 36 个报价，最大的切片也只有 4 卡，没有 8 卡整机，也都没有 `cluster_id`。
  - host 67231（英国）有 6 台 A100 PCIe 80GB，入网 7 到 8 Gbps，但都是 PCIe（没有 NVSwitch），而且同样没有 cluster。

## 结论

- 现在 vast.ai 上租不到两台能组多节点的 8×A100 80GB：市场上没有 8 卡的 A100 80GB，所有 A100 也都不在任何 cluster 里。
- 能在 vast 上组 2 × 8 的只有 cluster 80 的 RTX 5090（32 GB）。multinode.md 的 80 GB 档在 5090 上放不下，要另配更小的 flavor，也不是 A100。
- 已经被租走的机器不出现在搜索结果里，所以这只是当时的快照，过几天可以用上面的命令再查一次。
- 要 A100 SXM4 80GB 的 2 × 8，并且带 InfiniBand，得找 vast 以外、提供多节点集群的平台。本次没有查。
