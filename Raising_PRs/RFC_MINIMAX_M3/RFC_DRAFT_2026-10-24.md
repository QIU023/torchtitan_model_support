# [RFC] MiniMax M3 with MiniMax Sparse Attention training

## Summary

This RFC proposes adding MiniMax M3 to torchtitan with MiniMax Sparse Attention (MSA) trained the way its paper describes: block-sparse attention selected per GQA group by an indexer, and the indexer trained with a KL loss.

- MiniMax M3 is a natively multimodal MoE model (about 428B total and 23B activated parameters, 1M context) with MSA on layers 3 to 59 of 60; MiniMax-M3.1-Flash keeps the backbone and uses MSA on all 60 layers.
- Megatron-Bridge supports M3 but stores the indexer as frozen state and runs full causal attention on every layer, which matches MSA only up to 2048 tokens.

## The model

- Text decoder: 60 layers, hidden size 6144, GQA with 64 query and 4 KV heads of dimension 128, per-head QK RMSNorm, partial RoPE on 64 of 128 dimensions, zero-centered RMSNorm, untied embeddings, a 200K vocabulary.
- Layers 0 to 2: a dense FFN and full attention; layers 3 to 59: MoE (128 experts, top-4, sigmoid routing with a bias, 1 shared expert, clamped SwiGLU) and MSA.
- MSA: 4 index query heads of dimension 128 (one per KV head) and one shared index key head; token scores max-pooled to 128-token blocks; the top 16 blocks per query and GQA group, plus the local block.
- Vision tower: a CLIP-style ViT (32 layers, width 1280) with 3D RoPE, a 2x2 spatial and 2x temporal patch merge, and a GELU projector.

## MSA training

- The top-k selection is not differentiable, so the indexer learns only from the KL loss: the index distribution against the group-averaged main-branch attention on the selected tokens, with the teacher and the indexer input detached.
- The loss is `L_LM + lambda * sum(L_KL over layers)`.
- A warmup runs full attention while the indexer trains, then switches to sparse attention; the same schedule sparsifies a dense checkpoint.

## Plan

1. The eager model with FSDP2 on torchtitan's components, MSA as a FlexAttention inner attention over the selected blocks, the indexer KL loss, the Hugging Face state dict adapter, a debug flavor, and a numerical test against `transformers` (`minimax_m3_vl`) on a reduced config.
2. TP with SP, EP, CP (index keys and selected KV blocks across CP ranks) and PP, one PR each.
3. The released checkpoints: MiniMax-M3 (BF16), MiniMax-M3-MXFP8, MiniMax-M3.1-Flash (MXFP8 with packed NVFP4 experts).
