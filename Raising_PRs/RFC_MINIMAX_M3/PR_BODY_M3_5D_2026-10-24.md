## Summary
MiniMax M3 composes FSDP2/HSDP with tensor and sequence parallelism, expert parallelism and pipeline parallelism; context parallelism still raises.
- `torchtitan/models/minimax_m3/sharding.py` and `flavors.py`: MSA shards over TP with the index query heads following their KV groups and the shared index key head replicated, and an MSA layer gathers its input once for the q/k/v and index projections.
- `torchtitan/models/minimax_m3/attention.py`: `MSAIndexerLoss` normalizes by the global KV group count, and its logged value sums every TP rank's groups.
- `torchtitan/models/minimax_m3/model.py`: PP is no longer refused, and only CP raises `NotImplementedError`.
- `torchtitan/models/common/vision_encoder_sharding.py`: Qwen3.5's post-vision-scatter `transformer_block_sharding_config` moves here, and M3's layer 0 uses it.
- `torchtitan/models/common/vision_encoder_sharding.py`: one `vision_projector_sharding_config` replaces Qwen3.5's `vision_merger_sharding_config` and Kimi K2.7's identical `moonvit_projector_sharding_config`, for Qwen3.5, Kimi K2.7, Kimi K3 and M3.
- `tests/integration_tests/models.py`: the M3 models-suite cell runs FSDP 2 x TP 2 x EP 2 with SPMD typechecking.

## Design
- TP for MSA:
  - Each rank selects blocks, builds the flex block mask and computes the KL for its own KV groups, so selection needs no collective.
  - `msa_attention_sharding_config` gathers `x_TD` once at the MSA layer boundary.
  - The layer's `wqkv` is therefore a plain `Linear`, since a `ColumnParallelLinear` gathers again under SP.
  - `index_k_TI` enters the local attention region TP-replicated, so its gradient is partial and reduced the way MLA's headless inputs are.
- KL loss under TP:
  - Each rank divides its groups' KL by the global KV group count.
  - `MSAIndexerLoss` raises when the local groups do not tile the global count over TP.
  - The logged value adds the other ranks' groups through an all-reduce of the detached sum, and the injected gradient keeps this rank's part.
  - `collect_aux_loss_metrics` reduces over one mesh, and none spans dp, cp and tp.
- Context parallelism:
  - Each query's selection reads the index keys of its whole document, and the flex mask comes from that per-layer selection.
  - `AllGatherKVFlex.prepare_cp_metadata` rewrites a static `mask_mod`, so it does not cover MSA.
  - DeepSeek V4's sparse attention raises for CP the same way.
- Shared sharding configs: both moves leave the Qwen3.5, Kimi K2.7 and Kimi K3 debug configs identical, with SP on and off.
- Debug flavor:
  - The vision tower has 8 heads so TP 4 keeps two per rank.
  - With one head per rank, `VisionAttention`'s head merge is ambiguous to SPMD typechecking.
